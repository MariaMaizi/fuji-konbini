# Fuji Konbini｜富士山便利店

**在富士山脚下，给今天留一点停下来的时间。**

**简体中文** · [English](README.en.md)

[产品正交图](design/product-orthographics/README.md) · [运行说明](docs/README.zh-CN.md) · [技术结构](docs/architecture.md) · [验证记录](docs/verification.md)

一个结合 **3D 场景探索、商品浏览与对话店员** 的个人互动网页作品。你可以走进便利店，看看货架，与店员聊聊天，再把想要的商品加入购物篮、找到它在店里的位置。

我希望它带来一种轻松的停留感：清晨出发前挑一份早餐，午后找一点小零食，下雨时进来躲一会儿，或者在结束一天之后给自己一点奖励。

| 项目概况 | 内容 |
| --- | --- |
| 形式 | 可在本地运行的 3D 互动网页原型 |
| 场景 | 富士山、街景与便利店室内 |
| 核心体验 | 走进店里 → 浏览或交谈 → 选择商品 → 加入购物篮 → 店内寻路 |
| 商品目录 | 603 条：600 个建模商品条目、3 项咖啡服务 |
| 设计资料 | 30 张产品正交／多视图参考原图，按 7 类整理 |
| 主要工具 | Three.js、Blender、Node.js、GPT / Codex 辅助工作流 |
| 当前阶段 | 持续完善中；可本地体验，对话质量仍在迭代 |

## 从一间便利店开始

便利店里有很多适合做成互动的小选择：现在想吃热的还是喝一点东西，想吃饱还是随便垫一口，有没有特别想要的口味。富士山的背景则为这些选择提供了具体情境，让商品和旅行中的某一刻产生联系。

项目最初围绕场景与货架建模展开，随后逐步加入商品目录、人物视角、购物篮、寻路和对话店员。我关注的是怎样把这些部分连成一次完整的体验，让用户在场景里有理由继续探索。

## 一次进店体验

### 走近店铺，进入场景

浏览富士山与街景，切换天气和时段，再走进便利店。顾客有两种简化造型可选，支持第三人称探索和第一人称视角。收银台设置了 3D 店员，靠近后可以进入交谈。

### 自己逛逛，或者问问店员

想自己挑选时，可以打开 Browse，按分类浏览、搜索商品。想获得建议时，可以告诉店员自己的时间、心情或想吃什么，也可以继续追问、补充偏好。

固定店员面板使用英文，商品包装与招牌保留日文氛围；对话支持中文、日文和英文。外围场景仍有部分中文界面，完整站点的语言统一还在完善。

### 从一句建议走到货架前

推荐会关联目录中的商品卡。用户既可以单独添加一件，也可以将整组搭配加入购物篮；通过 Find 查看商品所在的位置并在店内寻路。这样，对话结果可以接回场景中的具体行动。

当前购物篮用于演示选择与数量调整，项目还没有真实下单、支付或履约功能。

## 设计上的几个选择

| 选择 | 考虑 |
| --- | --- |
| 2D 对话店员与收银台 3D 店员同时存在 | 让场景中的角色与易读的聊天界面配合，交谈时仍能保持对店内空间的认识。 |
| 浏览和交谈两条入口 | 用户可以自己找商品，也可以提出需求；一次体验可以在两种方式之间切换。 |
| 商品卡连接加购与寻路 | 把“推荐了什么”和“接下来能做什么”放在同一条体验里。 |
| 奶油色、绿色与较柔和的字体组合 | 延续便利店的日常氛围，并让聊天区域适合停留和阅读。 |
| 保留各类包装的不同形态 | 瓶、罐、盒、袋、杯和托盘共同构成货架的层次，帮助不同区域形成各自的视觉特征。 |

这些是项目迭代中形成的设计取舍。目前没有正式用户研究或转化率实验，因此不把它们描述成已被量化证明的效果。

## 从参考图到可交互网页

项目通过多轮反馈逐步推进：明确场景与商品方向，整理多视图参考，在 Blender 中处理模型、材质与陈列，再导出网页需要的 GLB 文件。不同区域以独立模块接入 Three.js，商品目录记录名称、模型节点和店内位置，使浏览、商品卡和寻路能够对应到同一件商品。

对话部分由浏览器调用 Node.js 后端，再连接模型 API。密钥保存在本地服务端配置中。当前审阅配置使用百炼的模型直答模式：模型理解输入并返回文字与商品 ID，界面将有效 ID 映射成商品卡。

模型接入和应用逻辑属于这个作品的实现范围；项目没有自行训练大模型。GPT / Codex 参与了参考图、代码和迭代辅助，Blender 承担模型处理。场景主题、审美偏好、功能方向和多轮取舍由创作者提出并确认，说明中保留这套实际协作方式。

## 当前进度与下一步

| 部分 | 当前进度 |
| --- | --- |
| 场景与探索 | 完整店内外场景、天气与时段、视角与简化顾客造型已接入。 |
| 商品与交互 | 603 条目录、搜索、单品与搭配加购、购物篮、店内寻路已接入。 |
| 对话店员 | 模型 API 已接入，保留中日英对话与商品卡联动；回复质量仍需完善。 |

| 人物细节 | 当前使用简化原型，尚未精确复现人物概念图，也没有完整骨骼动画。 |

对话店员仍可能补充缺乏依据的商品属性，或出现文字与商品卡不完全一致的情况。后续重点是检查真实对话中的一致性、改进浏览与移动体验，并继续完善商品素材和人物表现。

项目价格和食品资料包含虚拟门店设定与同类商品参考，不作为真实商品的现价、实测营养或过敏安全保证。项目与 7-Eleven 及相关品牌没有官方关联。

## 运行与查看代码

准备 Node.js 22 或更新版本，在仓库目录运行：

```sh
npm start
```

打开 **http://127.0.0.1:8011/** 即可体验场景与商品浏览。模型对话需要自行填写服务端 API 配置；详细步骤见 [中文运行说明](docs/README.zh-CN.md)。

```text
web/       场景、人物、商品交互、运行模型与图片
server/    本地服务、模型接口和离线测试
design/    产品正交／多视图原图画廊
docs/      运行指南、技术结构、素材说明与验证记录
scripts/   检查入口
```

整理版本时，203 项离线测试通过，603 条商品可对应到打包模型，网页依赖通过访问检查。离线测试使用模拟模型响应，验证范围详见 [检查记录](docs/verification.md)；真实模型的语义质量需要单独评估。
