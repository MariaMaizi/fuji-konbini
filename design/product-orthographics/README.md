# Product Orthographic References

## 商品正交／多视图参考图

**30 original sheets · 7 collections**

GPT-generated product references supplied by the project owner, collected from the modeling process. These sheets explore the packaging, silhouettes, and front, side, rear or top views used to develop the store. The views shown vary by product; they are visual modeling references rather than dimensionally verified engineering drawings.

这里收录你在建模阶段提供的 GPT 产品正交／多视图原图，保留原有排版和清晰度。共 30 张，按 7 类整理，点击分类即可浏览全部原图。

Each file is an unchanged copy of its saved source. Product-card label art, cropped thumbnails, texture atlases, furniture-only boards and screenshots are outside this collection. Some sheets contain earlier or unused designs, so the gallery is not a claim that every illustrated item is present in the current 603-entry catalog.

原图与最终建模可能有调整，也保留部分早期参考方案。当前门店商品仍以 `web/data/product-catalog.json` 和网页实景为准。
